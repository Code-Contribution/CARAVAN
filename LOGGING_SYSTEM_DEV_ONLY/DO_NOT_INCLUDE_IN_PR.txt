CARAVAN DEVELOPER LOGGING SYSTEM - DO NOT INCLUDE IN PUBLIC PR / RELEASE

IMPORTANT:
This entire LOGGING_SYSTEM_DEV_ONLY folder is developer/debug material only.
DO NOT copy, upload, commit, package, or add this folder when creating, updating, replacing, or reposting the public Caravan pull request in CodyTolene/pip-boy-3000-holotapes.

The normal Caravan files outside this folder have the lifecycle logger removed.

To temporarily restore diagnostics for hardware bug testing:
1. Back up the current active files.
2. Copy CARAVAN_GAME_LOGGING.JS to the project root as CARAVAN_GAME.JS.
3. Copy CARAVAN_GAME_LOGGING.MIN.JS to assets/CARAVAN_GAME.MIN.JS.
4. Test on hardware. The logging build writes CARAVAN.LOG using Pip.log().
5. When debugging is complete, restore the normal no-log CARAVAN_GAME.JS and assets/CARAVAN_GAME.MIN.JS before making any public package or PR.

Logging markers preserved in this backup include:
- READY
- RESULT <outcome>
- DATAFREE
- REMATCH
- AUDIOCORE
- AUDIOACTIVE
- AUDIOFREE

PUBLIC RELEASE RULE:
The public Caravan package/PR must contain NO LOGGING_SYSTEM_DEV_ONLY folder and must use the no-log active game files.
